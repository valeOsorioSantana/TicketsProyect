# 🎟️ TicketLite Frontend

Frontend de **TicketLite**, una plataforma web para la gestión, visualización y compra de tickets para eventos. El proyecto está desarrollado con HTML, CSS, JavaScript y Bootstrap, ofreciendo una experiencia moderna e interactiva para usuarios y administradores.

---

# 📌 Características principales

## 👤 Gestión de usuarios

* Registro e inicio de sesión
* Recuperación de contraseña
* Perfil de usuario editable
* Cambio de avatar e información personal
* Persistencia de sesión

## 🎫 Gestión de eventos

* Creación y edición de eventos
* Visualización detallada de eventos
* Vista previa del evento antes de publicarlo
* Sistema de favoritos
* Eventos guardados
* Calendario de eventos
* Eventos cercanos

## 💳 Sistema de compra de tickets

* Selección de entradas
* Flujo de compra interactivo
* Métodos de pago
* Confirmación de compra
* Validaciones de formularios

## 📊 Herramientas adicionales

* Estadísticas y gráficas
* Encuestas
* Chat en vivo
* Asistente IA
* Sistema de notificaciones
* Integración con redes sociales

# 🚀 Instalación y ejecución

## 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/tu-usuario/ticketlite-frontend.git
```

## 2️⃣ Entrar al proyecto

```bash
cd ticketlite-frontend
```

## 3️⃣ Instalar dependencias

```bash
npm install
```

## 4️⃣ Ejecutar el proyecto

```bash
npm start
```

El proyecto iniciará con Browser Sync.
